# Skill Eval 实施决定与证据

2026-10-22；当前设计 v0.5。local 与 live 分开记录，完整验收见 [acceptance.md](acceptance.md)。

| 事项 | 已实施/已验证 | 边界 |
| --- | --- | --- |
| 已有 Skill 来源 | 用户确认配置服务器只读目录；opaque ID + 内容指纹，复制导入 | 无配置返回 unconfigured，上传独立可用，不接受客户端任意服务器目录 |
| SDK / CLI | 两者锁定 beta.41；CLI commit 8690d27 | 预览服务滚动更新，最终验收实际 beta.44；未更新用户远端或全局 CLI |
| 新会话与模型 | 空 intent 新会话、上传前持久绑定；每 run 新会话，同 run 多轮沿用 | 请求身份与实际身份分开；root 模型观察结合 session 完整模型号确认 provider，不以别名或子 loop 猜测 |
| Skill 上传 | executable + base64；refs 激活 `octagon/eval-<run>` | skill_dir 是宿主机回执，不能作为沙箱路径；源包字节不暗改 |
| 无用户输入启动 | live：空用户提示/物料 + 可见平台指令“请执行本次选择的 Skill。”成功 | 真正空 wire message 曾无确定接受回执，不以它作为产品启动契约；平台指令与用户输入分开保存/展示 |
| 用户问答 | live：pause_tool_data → 真实 tool_call_id；结构化 selections/custom + 附件恢复 | 不使用旧类型提示的 prompt_id/answer，不自动代答；验证脚本答案是显式合成夹具，产品由用户提交 |
| 公开过程 | live：turn:snapshot、loop:turn、公开 thinking、tool_use/result；本地处理反序、跨 loop、复用 ID、summary | 私有推理与 provider 实际请求未提供；react 仅引用下一真实同 loop 模型事件，不宣称已证明隐藏因果 |
| 停止 / 结束 | live：新 API 真实中断、同会话继续、生成中 finish、最终回收及晚到消息拒绝 | 停止未确认可手动重试，不伪装成功；停止当前生成不等于整次结束 |
| 最终文件 | live：脚本直接执行、二进制输出 hash、输入原字节、补附件、最终下载 | 两次匹配读取只确认单文件，不承诺跨文件原子快照；回收失败与零文件区分 |
| 重跑 | live：完整用户输入/回答/附件，一次上下文发送，replace 可全空 | 每次手动确认，来源新增输入使确认失效，不带旧模型输出、产物或备注，不静默截断 |
| 保存与导出 | local + live：未保存整包试跑/导出，beta 原号保存，另号发布保留原 beta | 正式版不覆盖；泛快照导出元数据不依赖可变 release；所选版本与历史 run 显式冻结标签 |
| 证据存储 | 策略过滤后的来源 JSON 与 seq 直接写 SQLite；事务后通知 | 不另写 raw/JSONL 镜像，避免双写；原始事实不被投影覆盖，body 省略原因可见 |
| 投影分页 | 固定 schema/head 的可重放分页，SSE DB seq 续读 | 计算开销随历史长度增长，尚无二级投影缓存；不存在历史保留清除时的伪空结果 |
| 恢复 | 本地故障注入：未知 create 不再建会话、绑定后上传恢复、已接受会话只读对账、坏记录隔离、作用域与排他锁 | 不确定且无法对账的投递保留可解释失败，不盲目重发或冒充续聊；真实进程崩溃穷举不作为已经验证的承诺 |
| 孤立对象清理 | 显式 GC、全引用扫描、文件锁跨进程互斥、DB 引用事务；提交竞态测试通过 | 不自动删历史/会话；损坏引用使 GC fail closed |
| 首期范围 | 支持读取输入、文字结论与新文件；所有页面有局限说明 | 不评估外部写入或原地修改物料的实际效果，不承诺强制拦截、验证或回滚 |
| 空闲保留 | 配置 null，不对等待用户状态启动生成计时器 | 远端空闲保留期限未知，不能承诺永久续聊 |
| 依赖与门禁 | multipart 为运行依赖；后端全量 + 新模块前端门禁 + build | 旧前端 88 项失败独立记录，不把它们说成全量通过；Vitest 故意失败探针返回 1，已删除探针 |
