## 验证

最后本地后端、新模块及旧 Blade 聚焦测试的准确结果见验收记录。新前端 29 项通过、build 通过；全前端 94 passed / 88 failed，失败数与原有基线一致，不称全量前端通过。

真实 HTTP→Worker→SDK 主链覆盖三次运行、结构化回答+附件、未保存微调重跑、全空启动、最终字节、三次比较及发布导出重导。另一链验证真实停止→同会话继续→生成中主动结束→晚到输入拒绝。四个自建会话均已清理，报告没有 PAT。详见 [blade-verification.md](blade-verification.md)。
