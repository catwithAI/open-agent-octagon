## 1. 工作区与实验

现有 `J3xEIv`（Skill 详情与运行历史）需要：

- 增加实验选择、新建和改名入口；创建实验填写名称，绑定当前 skill，不能在已有实验中切换其他 skill。
- Skill 历史默认可汇总全部实验，提供实验和版本筛选；记录列加入实验名、用户版本及内容修改标记。
- 版本区域显示版本号与“未发布／已发布”，不根据 beta 字符串判断状态。缺版本的首次导入确认默认 `0.0.1`。
- 运行配置处常驻展示首期范围：读取输入、生成文字结论或新文件；暂不支持写外部系统、原地修改／删除上传物料。不能暗示执行层已强制拦截；无需额外确认弹窗。
- 提示和物料明确标为可选，没有这两项时运行仍可用；智能体仍只有 blade-agent。
- 区分“保存版本”“发布正式版”“试跑”“导出当前内容”，试跑和导出不能触发版本保存。

新增：实验为空、新建实验、切换实验、版本选择与实验／版本历史筛选状态。

## 2. 导入确认与同名冲突

新增导入确认面板：展示识别的名称、版本、包资源和校验状态。

| 情况 | 交互 |
| --- | --- |
| 首次无版本 | 预填 0.0.1，显示未发布状态 |
| 同名无版本 | 阻止完成导入；要求改为未使用名称或填写该 skill 未使用的版本号 |
| 同名重复版本 | 同样阻止，包括目标为未发布／beta；不提供覆盖旧 beta 的选项 |
| 同名新版本 | 明确归入已有 skill，新增未发布版本，旧版本／历史保持不变 |
| 并发版本占用 | 保留文件及输入，定位版本号冲突，允许换号后再次确认 |

名称与版本号可调整，冲突不要求重新选择上传文件。新增包解析中、冲突、可提交、过期需重传等状态。

## 3. 微调与版本保存／发布

现有 `Q0n0BA`（脚本编辑）、`ZfHFM`（SKILL.md 编辑）、`DdcrF`（批注 E）需要：

- 保留左来源证据与右多文件编辑，不把一轮对话等同于独立运行结果。
- 将“保存工作副本”调整为明确的“保存版本”：已有未发布版本可原号保存全部文件；展示保存目标号与修订状态。
- 来自正式版的编辑保留来源标记，首次保存要求新版本号，保存为未发布版本；不提供覆盖正式版。
- “发布正式版”单独弹窗，必须填写未使用的新版本号，说明另建正式版、保留原未发布版本。
- 将“保存快照并重跑”调整为“试跑／重跑”，无需先保存版本；运行只冻结全部编辑内容。未保存缓冲仍显示未保存，不能误报“版本已保存”。
- 导出当前内容包含所有未保存文件改动，不触发版本保存，也不发布。

新增：原号保存 beta、正式版派生首次保存、发布新版本及号冲突、未保存直接试跑状态。

## 4. 重跑输入必经确认

新增独立确认面板，两种方式由用户手动选择，不预选后直接运行：

- **带上全部用户输入与附件**：展示初始提示、所有用户回答／追问及上传附件；保留顺序与来源，不自动带旧模型回复、生成产物或远端会话状态。
- **重新提供**：清空旧用户输入与附件，允许重新填写／上传，也允许两项均为空。

同时显示 skill 内容／模型变更摘要，确认后新建会话与运行。来源运行在确认期间新增用户输入时，提示更新清单并重新确认。返回编辑器保留全部文件缓冲。

## 5. 单次运行的正常多轮使用

现有 `hFctv`（运行详情）需要较大调整：

- 增加对话输入区、附件上传和已上传附件列表；未结束前支持正常追问及补充说明。
- 智能体提问显示问题及用户真实回答入口，支持文字和附件；问题回答不能用平台自动生成的答案代替。
- 一轮模型回复完成展示“等待继续”，不展示整次运行已完成。
- “停止当前生成”与“结束本次运行”分开；后者明确固定最终结果、结束后不可再向此运行发送消息。
- 运行结束后展示最终结论、真实过程及可选的新文件产物；文字结论且零文件是正常结果。提供评测范围说明入口；超出范围的操作不显示为副作用验证成功。不提供各轮产物版本或回退选择。
- 当前 skill 始终显示启动快照，微调后的内容提示需重跑才生效；用户版本后续保存不改变当前运行。
- 保留每次运行一个“备注（可选）”，不为每轮对话加独立备注；结束后仍可补充／修改／清空备注。

新增：生成中、等待用户回答、等待继续、附件发送失败、停止确认中、结束回收中、已结束只读、失败部分结果和刷新恢复状态。

## 6. 完整流程

现有 `v4Wiig`（思考行动与反馈）、`XoQgc`（批注 B）需要：

- 时间线加入真实用户问题、回答和附件关联，区分用户对话轮次与模型／工具调用轮次。
- 明确“模型本轮回复完成”和“用户已结束运行”的区别。
- 默认展示可获得的公开思考、工具参数和返回正文，并显示有效采集范围、限制和缺口。
- 保留实际事件、并行调用配对、react 与上下文入口，不添加隐藏推理或根据前后时间编造因果。
- 过程可以逐轮回看，但不提供“恢复本轮产物”或“按此轮结果比较”。

## 7. 历史与比较

现有 `FW0SQ`（全局记录）、`Tvlj4`（三次比较）、`W4UPN1`（批注 C）需要：

- 全局仍按智能体／provider／模型归组，二级记录补充实验、skill 版本、运行状态及备注摘要；增加实验／版本筛选。
- 选择不同实验（也可不同 skill）的终态运行进行比较；未结束运行提示“请先结束本次运行”。
- 每列只展示结束时的最终结果、可观察过程、可选最终产物和整次运行备注；文字结果可比较，外部写入／原地修改输入的实际效果不在首期比较范围；删除较早轮次选择及历史产物选择的设想。
- 对比完整初始及追加用户输入、附件、skill 快照、模型差异；生成消息只在过程视图回看，不自动变成重跑输入。
- 失败／取消的已结束运行可查看已回收结果，比较时标明不完整；产物无法获取时不显示空白成功。
